# UMAIR MECHANIC — V3

A cinematic, single-page website concept for a motorcycle customisation workshop in Nallasopara, Maharashtra, India.

## Project Overview

The website showcases Royal Enfield customisation concepts through immersive visuals, scroll-driven animation and interactive sections.

## Features

- Cinematic hero section with scroll-controlled motorcycle animation.
- HTML Canvas rendering with 243 optimised WebP frames.
- GSAP and ScrollTrigger animations.
- Motorcycle showcase with three design concepts.
- Interactive before-and-after comparison slider.
- Workshop and craftsmanship sections.
- Customer enquiry modal.
- WhatsApp enquiry integration.
- Responsive layouts for desktop, tablet and mobile.

## Technology Stack

| Technology | Purpose |
|---|---|
| HTML5 | Structure |
| CSS3 | Styling and responsive design |
| Vanilla JavaScript | Interactions and logic |
| GSAP | Animations |
| ScrollTrigger | Scroll-based animation |

## Run Locally

1. Clone or download the repository.
2. Open the project folder in VS Code.
3. Run `index.html` using the Live Server extension.
4. Open the local URL in your browser.

## Hero Animation

The hero animation uses 243 individual WebP frames rendered on an HTML Canvas.

GSAP ScrollTrigger synchronises the displayed frame with the user's scroll position.

## Deployment

This is a frontend-only static website and can be deployed using:

- GitHub Pages
- Netlify
- Vercel

## Current Scope

This is a frontend website concept. It does not currently include a backend, database, authentication system or admin dashboard.
